# video-studio

用 Claude Code 做视频：代码动画（HyperFrames / Remotion）、按文字稿剪素材（转写 + ffmpeg）、调度 AI 视频模型、Manim 讲解动画。

- 流程和规则：[CLAUDE.md](CLAUDE.md)
- 每条视频一个目录：`videos/<编号>-<短名>/`
- 素材和渲染结果不进 git

## 依赖

- Node.js 22+
- ffmpeg
- Chrome / Chromium（HyperFrames、Remotion 渲染用）
